# nestjs-devtron-demo

Public NestJS app used to try a Devtron build and deploy.

`GET /` returns the service name. `GET /health` returns `{ "status": "ok" }`. The process listens on `0.0.0.0` and `PORT` (default `3000`).

## Devtron

- Git repository: this repo, branch `main`
- Dockerfile path: `Dockerfile`
- Container port: `3000`
